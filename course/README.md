# Будова курсу

Курс працює без фреймворків і серверної частини. `index.html` завантажує `js/engine.js`,
потім файли уроків, після чого викликає `COURSE.start()`. Маршрути: `#/` та `#/l/p27`.
`css/app.css` підтримує вузькі екрани та системну темну тему.

## Додати параграф

Створіть `js/lessons/pNN.js` за зразком `p27.js`:

```javascript
COURSE.addLesson({
  id: "pNN",
  label: "§ NN",
  group: "Назва тематичної групи",
  groupSub: "Розділ, діапазон параграфів і сторінок",
  pages: "79–81",
  title: "Назва",
  subtitle: "Короткий вступ",
  goals: ["Що треба знати"],
  blocks: [],
});
```

Ідентифікатор сторінки та `id` питання входять у ключ прогресу; зберігайте їх при редагуванні.
Скрипт зареєструйте в `index.html` перед `COURSE.start()`, у порядку проходження курсу.
Підсумковий тест — той самий формат із `exam: true`, 12 питаннями та IDs `t1`–`t12`.

## Блоки

| Тип | Основні поля | Призначення |
|---|---|---|
| `text`, `note`, `summary` | `html`, за потреби `title` | Конспект, акцент, головна думка |
| `cherkasy`, `ukraine`, `potter`, `horse`, `life`, `game` | `html`, за потреби `title` | Шість контекстних врізок |
| `image` | `src`, `caption`, `alt`, за потреби `max` | Малюнок із `img/`; `max` обмежує ширину |
| `gallery` | `cols`, `items: [{src, caption, alt}]` | Малюнки поруч |
| `terms` | `items: [{t, d, book?}]` | Термін, просте пояснення, книжкове означення |
| `fold` | `title`, `html` | Додаткове пояснення або усна самоперевірка |
| `errata` | `book`, `truth`, `say` | Помилка, виправлення, відповідь на уроці |
| `quiz` | `id`, `question`, `options`, `answer`, `explain`, `wrong?` | Одна відповідь; індекс починається з нуля |
| `multi` | `id`, `question`, `options`, `answers`, `explain` | Повний набір правильних індексів |
| `order` | `id`, `question`, `items`, `explain` | `items` записують у правильному порядку; рушій перемішує |
| `input` | `id`, `question`, `accept`, `explain`, `hint?`, `placeholder?` | Допустимі варіанти відповіді |

Відповіді `input` порівнюються без регістру, зайвих пробілів і кінцевої пунктуації;
варіанти апострофа нормалізуються. Використовуйте лише довірений авторський HTML у даних уроку.

## Зміст і малюнки

Порядок: конспект із малюнками → терміни → головна думка → шість врізок → згортки → питання.
Виправлення ставте біля помилкового твердження. На параграф потрібно вісім питань
усіх чотирьох типів, три або більше простих прикладів у `life` та зв’язок із Україною/Черкащиною.

Ілюстрації зберігайте як RGB JPEG у `img/`, з назвою латинкою через дефіси.
Підписуйте джерело й книжкову сторінку. Перевіряйте порядок за виглядом сторінки:
порядок PDF-об’єктів не відповідає порядку підписів. Не розтягуйте маленькі або вертикальні
малюнки на всю ширину; використовуйте `max` або окремий блок.

## Перевірка

З кореня проєкту: `node course/tools/check-content.js`, потім `node course/tools/check.js`.
Із папки `course/`: `node tools/check-content.js`, потім `node tools/check.js`.
Обов’язковий зміст записуйте в `tools/coverage.json` малими літерами, словами або коренями,
які видно на сторінці. Нову підтверджену помилку додайте в `tools/errata.json` і блок `errata`.
Для розширення за межі §14–35 оновіть очікувані діапазони в обох перевірках.
