# Історія, 6 клас

Інтерактивний курс за §14–35 підручника О. В. Гісема та О. О. Гісем
«Історія України. Всесвітня історія. 6 клас» (Ранок, 2023).

22 параграфи, чотири підсумкові тести, 224 завдання. У кожному параграфі — конспект,
ілюстрації з підручника, терміни, головна думка, шість контекстних врізок і вісім питань.
Тести містять по 12 питань: §14–19, §20–24, §25–29 та §30–35.

## Відкрити локально

Відкрийте [course/index.html](course/index.html) у браузері. Встановлення пакетів і збірка не потрібні.
Для локального сервера з кореня проєкту:

```powershell
python -m http.server 8000 --directory course
```

Адреса: `http://127.0.0.1:8000/`. Прогрес зберігається в браузерному `localStorage`
під ключем `istoriya6.v1`. Інший браузер або перехід між локальним файлом, сервером
і опублікованим сайтом має окреме сховище прогресу.

## Перевірити

```powershell
node course/tools/check-content.js
node course/tools/check.js
```

Перша команда перевіряє всі сторінки, структуру питань, обов’язковий зміст, виправлення
та шляхи до малюнків без браузера. Друга запускає Chrome й перевіряє відображення,
відповіді, малюнки та збереження прогресу. Потрібен Node.js із вбудованими `fetch`
і `WebSocket` (перевірено на Node 24); для Chrome поза стандартним шляхом задайте `CHROME_PATH`.
Сервер можна перевірити командою `node course/tools/check.js http://127.0.0.1:8000/`.
